# Portrait assets

Optional PNG portraits for the snake skins.

File names:

- `生肖_灵鼠.png`
- `灵鼠.png`

Recommended format: square transparent PNG, 512x512 or larger.

The game loads these images automatically when present and applies a subtle
idle bob/sway. If no image exists, it falls back to the procedural portrait.

Do not commit character art unless you have the rights to use and redistribute it.
